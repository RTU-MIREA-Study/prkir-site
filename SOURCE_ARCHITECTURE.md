# Клиентская часть «Домашний психолог»

Откройте main/index.html после распаковки сайта. Для проверки ES-модулей по HTTP: python -m http.server 8784 из корня архива, затем /main/index.html.

- HTML: пять основных экранов, самостоятельная страница анимаций, политика и две страницы учебных демонстраций.
- Общие компоненты БЭМ: site-header, site-nav, site-footer, booking-form. Элементы имеют имена __inner, __list, __grid, __row, __card. Упражнения сохраняют собственные локальные классы.
- ITCSS: style.css импортирует settings → generic → elements → objects → components → utilities → themes.
- script.js импортирует `initTheme` из theme.js. theme.js сохраняет только light/dark в localStorage, обрабатывает недоступность хранилища и обновляет aria-состояние.
- practice.js — модуль учебных алгоритмов. site-entry.js загружает модули по HTTP и использует классическую сборку site-local.js при открытии файла. Слайдер подписывается на события кнопок и обновляет aria-pressed.
- Формы демонстрационные: валидация происходит локально, запросы на сервер не отправляются. Обращения и пароли не сохраняются.
- Данные каталога — массив JavaScript; корзина — локальное состояние страницы; переключатель темы — единственное сохраняемое пользовательское состояние.

Три сценария: услуги→контакты; о специалисте→отзывы→форма; тема→другая страница→восстановление. Страница самостоятельной работы 404.html доступна через ссылку с копирайтом. Из неё открываются дополнительные CSS и JavaScript-упражнения.
